# Ministry Website Image Library (`images/`)

This directory stores hero banners, crusade gallery photos, devotional article covers, and branding assets for Ali Welekhasia's official website.

## Main Files:
- `images/hero.jpg` - Primary website hero section background image
- `images/crusade-gallery/` - Open-air revival crusade photos
- `images/devotionals/` - Spiritual devotional article covers
- `images/uploads/` - Custom admin uploaded pictures
